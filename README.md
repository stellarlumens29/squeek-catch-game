# Squeek Catch

A simple tap game built on Squeekchain. Catch falling cheese with the mouse, avoid bombs, and chase the Golden Rush while Squeektoshi is running on the real wheel.

## How to play

- Move the mouse with your mouse, touch, or arrow keys
- Catch cheese: +10 points, golden cheese: +30 points
- Avoid bombs: -1 life, -15 points
- 5 catches in a row: +20 combo bonus
- 60 seconds per round, level rises every 15 seconds

## The Squeek Wheel — Live

The game reads Squeekchain live from `api.squeekchain.com`:

- When the real wheel is **SPINNING**, Golden Rush is active and golden cheese spawns far more often (about 36% of spawns, up from about 11%)
- When the wheel is **IDLE**, the game plays in normal mode
- Live status, block height, and RPM are shown in the widget and refresh every 20 seconds

Built on Squeekchain (Ethereum Sepolia, chain ID 11155111).

- Squeekchain: https://squeekchain.com
